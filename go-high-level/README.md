# GoHighLevel

## What's Included
### [GTM](gtm/)
#### [GTM Tags](gtm/gtm-tags/)
- **GHL Form Submit Bridge:** Listens for postMessage from GHL, adds ghl_form_submit event to website.
- **GHL Chat Widget Bridge:** Pushes GHL chat widget open and lead-submit events to the dataLayer.
- **GHL Tracking Template:** complete .json file ready for import into GTM. Includes all Tags, Variables, and Triggers needed for complete setup. Anonymized IDs.

#### [GTM Variables](gtm/gtm-variables/)
- **GHL GTM Variables:** .json file with only the variables from the GHL Tracking Template, ready for import into GTM. README includes a table of every variable and its configuration.
